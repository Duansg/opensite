当很多界面都选择柔和的渐变、圆角和模糊阴影时，另一种视觉语言选择把结构直接摆出来：粗边框，平涂色块，几乎像纸片叠起来一样的硬阴影。

这是新野兽派吸引人的地方。它不回避数字界面的人工痕迹，反而让按钮看起来像按钮，让区块拥有清楚的边界。

## 用有限的规则建立性格

强烈的视觉风格，不意味着每个元素都要大声说话。先选定几条规则，然后反复使用。

- 用同一种黑色定义文本、边框和阴影。
- 用一个主色建立背景气氛。
- 用少量亮色表示强调与状态。
- 让间距与像素网格共享一套尺度。

这个博客的主色是蓝紫色，辅助色是黄色、薄荷绿和淡紫色。它们出现在不同位置，却承担稳定的角色。

## 为什么像素艺术很合适

像素艺术和新野兽派共享一种诚实：你能直接看见构成图像的基本单位。前者把像素保留下来，后者把边框和层次保留下来。

当像素人物与粗标题放在一起，画面会产生一种介于早期互联网和现代编辑设计之间的趣味。

### 克制装饰的数量

像素角、网格与粗阴影都很有辨识度。全部同时使用时，容易让正文失去呼吸空间。更好的办法是把强烈元素集中在首页、封面和操作区域，正文保持清晰。

## 让交互延续同一套语言

一个有硬阴影的按钮，可以在悬停时抬高两像素，按下时回到阴影所在的位置。动作不需要复杂，用户就能感觉到它的「重量」。

```css
.button {
  border: 2px solid #0d0f12;
  box-shadow: 4px 4px 0 #0d0f12;
}

.button:active {
  transform: translate(4px, 4px);
  box-shadow: none;
}
```

## 风格最终要服务于阅读

让人记住的网站，不只有外观。它还需要清楚的导航、舒适的行距、足够的对比度，以及在小屏幕上同样顺畅的体验。

有性格和好用并不矛盾。设计规则越明确，就越有空间照顾那些细小却重要的阅读细节。
